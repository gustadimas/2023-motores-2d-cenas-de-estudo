# Motores 2D: cenas de estudo

Projeto da faculdade, de abr/2023 a mai/2023. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Pacote com as cenas que fiz nas aulas de motores 2D entre abril e maio de 2023. Tem plataformas que se movem e uma roda de plataformas girando, um semáforo que usei pra aprender corrotinas, uma tela de login, a atividade de Canvas e uma cena testando a responsividade da interface.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/MotoresDimas.unitypackage` em Assets > Import Package > Custom Package.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
